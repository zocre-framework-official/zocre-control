# ZOcre Control

**L’application Windows pour installer et gérer vos serveurs nanos world.**

[Télécharger ZOcre Control 1.0.46](https://github.com/zocre-framework-official/zocre-control/releases/tag/v1.0.46) · [Discord officiel](https://discord.gg/Ey4dn4Cbqj) · [Support](SUPPORT.md)

## Français

ZOcre Control rassemble l’installation d’un serveur nanos world standard et la gestion de plusieurs serveurs indépendants dans une interface en français et en anglais.

### Installer l’application

1. Téléchargez **ZOcre-Control-Setup-1.0.46.exe** depuis la release officielle et comparez son empreinte SHA-256 à celle publiée.
2. Lancez le Setup, choisissez le dossier de l’application et associez votre compte Discord.
3. Le rôle Membre du Discord officiel est requis. Lisez la licence et acceptez-la si vous êtes d’accord, puis suivez la progression de l’installation.

Choisissez ensuite un dossier distinct pour chaque serveur. L’application vérifie la destination avant de commencer une nouvelle installation.

### Fonctions disponibles

- Installer un serveur **nanos world standard**.
- Sélectionner et gérer plusieurs serveurs indépendants ; démarrer, arrêter ou redémarrer le serveur sélectionné.
- Consulter sa console et ouvrir son dossier depuis les actions serveur.
- Utiliser les sauvegardes et l’importation de serveurs compatibles, avec les contrôles de destination et de conservation affichés.
- Rechercher les mises à jour du serveur nanos world et de ZOcre Control ; les opérations serveur indiquent lorsqu’un arrêt est nécessaire.
- Signaler un bug avec un message, des diagnostics préparés automatiquement et jusqu’à cinq pièces jointes facultatives.

**Cette version ne déploie pas ZOcre Framework et ne fournit pas de mise à jour des kits de développement ni des scripts du framework.**

### Compte Discord et mises à jour

Après la première association, votre compte reste associé au profil Windows. L’appartenance au Discord officiel et le rôle requis sont revérifiés automatiquement pour les opérations protégées. Une perte du rôle, un départ ou un bannissement empêche un nouvel accès protégé.

Les serveurs nanos world déjà installés et leurs fichiers restent utilisables indépendamment de ZOcre Control. Le fonctionnement du serveur nanos world standard ne dépend pas de votre association Discord à l’application.

### Désinstallation et réinstallation

Désinstallez **ZOcre Control** depuis les applications Windows. Les serveurs, leur catalogue et vos réglages sont conservés ; le compte Discord est déconnecté. Lors d’une réinstallation, refaites simplement l’association Discord. Les serveurs conservés peuvent réapparaître dans la gestion ; utilisez l’importation compatible si vous devez les rattacher de nouveau.

### Signaler un problème

Cliquez sur **Signaler un bug**, décrivez le problème, sélectionnez éventuellement vos fichiers, puis cliquez une fois sur **Envoyer le rapport**. L’envoi est volontaire et arrive au support privé. Un export ZIP reste disponible. Consultez [SUPPORT.md](SUPPORT.md) avant de joindre des fichiers.

## English

ZOcre Control is a Windows x64 application for installing standard nanos world servers and managing several independent servers, with French and English interfaces.

Download **ZOcre-Control-Setup-1.0.46.exe** from the official release, check its SHA-256 digest, choose the application folder, link your Discord account and accept the product licence if you agree. The official Discord Member role is required for protected access. After linking, membership checks for protected operations run automatically.

Available features include standard nanos world installation, per-server start/stop/restart, console access, opening the selected server folder, compatible backup/import operations, server and application updates, and voluntary private bug reports with optional attachments.

**This release does not deploy ZOcre Framework or update development kits or framework scripts.** Existing standard nanos world servers remain usable independently. Windows uninstall preserves servers, their catalogue and settings, while disconnecting Discord; reinstallation requires linking the account again.

For support, use **Report a bug** or see [SUPPORT.md](SUPPORT.md). Review selected files before sending them.
